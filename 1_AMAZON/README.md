
# Amazônia

1. Censo_UPA04.xlsx (Para mais detalhes: https://portal.edirepository.org/nis/mapbrowse?packageid=knb-lter-hfr.339.3)
2. LCF5900_AMAZON.R (R script para acesso à tabela Excel)

Tabela contém uma lista de árvores inventariadas em 2010 para um plano de manejo em área localizada às margens da BR 364 no município de Porto Velho, Rondônia. Disponível no formato `XLSX` e `shape`, os dados se referem às árvores da UPA (Unidade de Produção Anual) número 4.  A tabela abaixo apresenta os códigos usados para identificar o destino das árvores inventariadas.

| Código | Destinação |
|--------|------------|
| APP | Em área de preservação permanente |
| CF | Corte futuro (árvore com DAP entre 40 e 50 cm) |
| CPL | Corte protegido por lei |
| PAB | Para abate |
| PS | Porta semente |
| RAR | Rara |
| REM | Remanescente |
